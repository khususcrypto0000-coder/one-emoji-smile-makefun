Entry for the make.fun bounty **"One Emoji, One Smile"** (`u-0xkianno-one-emoji-one-smile-5470751f`).

## The entry

`main.py` writes exactly one emoji to `/output/entry.txt` — and nothing else:
no words, no caption, no explanation.

The chosen emoji is 😌 (U+1F60C, relieved face): a gentle, closed-eye smile
that reads as calm, warm and friendly at a first glance. It is universal
across ages and backgrounds, clearly picked rather than the first default
smiley, and it carries no intimacy, sarcasm or flirtation — just a quiet,
kind warmth meant for a stranger.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (UTF-8, exactly one character, no trailing
newline) and verifies the file by reading it back byte-for-byte.
